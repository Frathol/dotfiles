# My Dotfiles 

It's just like a backup for my dotfile for Arch in case something happens.

## Prerequisites & Dependencies

To ensure all configurations (Hyprland, Wayland, Audio, and Terminal) work out of the box, make sure to install these packages:

### 1. Window Manager & UI
- `hyprland`: The main Wayland compositor.
- `waybar`: Highly customizable status bar.
- `swaybg`: For wallpaper management.
- `swayosd-git`: For modern On-Screen Display (Volume/Brightness pop-ups).
- `network-manager-applet`: GUI for network management.

### 2. Terminal & Shell
- `kitty`: GPU-accelerated terminal emulator.
- `zsh`: The interactive shell.
- `starship`: Cross-shell customizable prompt.
- `zsh-autosuggestions` & `zsh-syntax-highlighting`: Essential Zsh plugins.
- `fastfetch`: System information tool.

### 3. Audio & Networking
- `pipewire`, `wireplumber`, `pipewire-pulse`: Modern audio stack.
- `networkmanager`: Network management service.
- `ufw`: Uncomplicated Firewall for security.
- `networkmanager-openvpn`: OpenVPN support for NetworkManager.

### 4. Development Tools
- `neovim`: Extensible text editor (configured with LazyVim).
- `git`: Version control system.
- `ripgrep`, `fd`, `fzf`: Search and fuzzy finder tools for Neovim.
- `gcc`, `make`, `unzip`: Build tools for Neovim plugins.
